- Ровно пять мер, допустимый бюджет 100, превышение, повторы даже в разных районах, третья мера направления.
- M1/M3 в одном и разных районах; M4/M7 и M5/M13 в одном и разных районах; конфликт после изменения района.

- Фильтры пяти направлений, выбор, удаление и замена без шестого слота.

- Загрузка, ошибки 422 и 500, не-JSON ответ, недоступный backend, таймаут, явное включение mock.
- Повторная отправка блокируется; ошибка сохраняет план.
- Ошибка explain сохраняет результат; объяснение можно загрузить повторно.
- Разные числовые результаты simulate/explain не смешиваются.
- Метки llm/fallback, безопасный вывод текста, отсутствие выполнения HTML из объяснения.
- Изменение плана скрывает текущий старый результат; история остаётся.
- Повреждённые данные, отсутствие полей/района/исходного показателя в сохранённом ответе, ошибка записи хранилища.
- Сохранение названия и решений, реальное восстановление после remount, совместимость снимков данных, сравнение критических показателей, удаление и отмена удаления.

Числовые fixtures в тестах сохранены из реального Go API. В приложении они не используются.

## Не выполнено / перед выступлением

Браузерный инструмент вернул пустой список браузеров. Попытки открыть Chrome и встроенный браузер завершились `Browser is not available`. Поэтому ниже **нет отметок об успешной визуальной проверке**.

- [ ] **390 px:** нет горизонтальной прокрутки всей страницы; карточка и select читаются; нижняя навигация и строка плана не закрывают фокус, сообщения и запуск; таблицы прокручиваются внутри своих областей.
- [ ] **768 px:** каталог и закреплённая панель не пересекаются; заголовки и длинные названия не обрезаются; все кнопки доступны.
- [ ] **1440 px:** две колонки карточек, пять слотов, бюджет и запуск видимы; результат понятен без раскрытия всех подробностей.
- [ ] Реальные Tab / Shift+Tab / Enter / Space / стрелки; видимый фокус на кнопках, select, summary и таблицах; после удаления фокус возвращается к плану.
- [ ] Системный reduced motion: выключены spinner, переходы и анимация появления (CSS предусмотрен, реальная отрисовка не проверена).
- [ ] Touch и экранная клавиатура телефона; Safari; масштаб текста 200%; экранный диктор.
- [ ] Реальный LLM с ключом, внешний production-origin и CORS, потеря сети в браузере во время ответа.

DOM-тесты не проверяют расположение пикселей и не заменяют эти пункты. Сетевые ошибки и таймауты frontend проверялись контролируемыми ответами; успешный основной поток и fallback — дополнительно живым Go.

## Ограничения продукта

1. Mock предназначен для каталога и редактирования; расчёт отключён.
2. API не возвращает версию движка. Снимки разных данных явно помечаются как несопоставимые; одинаковые снимки не гарантируют одинаковую версию Go.
3. История находится только в localStorage текущего origin. Нет облачной синхронизации и согласования изменений между вкладками. Квота браузера конечна, ошибка записи показывается пользователю.
4. Fallback API содержит сильные стороны, риски и компромиссы, но не отдельный раздел рекомендаций. Frontend не дописывает его.
5. Все показатели синтетические. Иллюстрация Астаны не является географической картой районов; декоративных графиков, событий и таймера нет.
6. Go пересчитывает план и в simulate, и в explain. При несовпадении ответов объяснение не прикрепляется, доступный результат сохраняется.

Повторно выполнено после переноса:

- `npm run test:integration`: **1 / 1 passed** с живым обновлённым Go.
- `npm run test:api`: passed; дополнительно проверен `mode=best`, его Score 57.236734999999996 и стоимость 98 совпали с независимым `/api/simulate`.
- `npm run build`: passed, результат в `web/dist`, ошибок TypeScript нет.

- Бюджет/валидность черновика теперь подтверждаются Go. Старые данные скрываются сразу после изменения плана; запоздалые ответы игнорируются.
- `503 not_ready → Считается… → повтор через 2 секунды → 200` проверено управляемыми HTTP-ответами в тесте компонента. Отмена ожидания, уход со страницы и отсутствие автоматического повтора иных 503 также проверены. При живом HTTP-тесте оптимизатор уже был готов; живой стартовый 503 в этом запуске не наблюдался.
- Проверено исключение node_modules и dist из Git. Ветка опубликована отдельно от main.
